# FaunaVault-01.github.io

FloraVault Pro brings plant and pet care routines together in one calm, beautiful dashboard. Track your living collection, care schedules, notes, and climate metrics—all in one place.

## Website

The website address is <https://a-colp01.github.io/FaunaVault-01.github.io/>.

To publish the site:

1. Open **Settings → Pages** for this repository.
2. Under **Build and deployment**, set the source to **GitHub Actions**.
3. Push the `main` branch to GitHub. The workflow in `.github/workflows/pages.yml` will deploy the site.
4. After the Pages deployment succeeds in the **Actions** tab, visit the address above. The QR code on the site opens this same address.

The site is a static page served from [index.html](./index.html). GitHub Pages must be enabled and the deployment workflow must succeed before the website and its QR code can open successfully.
